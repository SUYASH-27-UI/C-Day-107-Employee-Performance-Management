# C Day 107 – Employee Performance Management System

## Description
A menu-driven C application for managing employee performance records.

## Features
- Add employee records
- View all employees
- Search by employee ID
- Update performance scores
- Calculate average performance
- Store records in a text file

## Technologies Used
- C Programming
- Structures
- Arrays
- Pointers
- File Handling

## Files
- `performance.c` – Main program
- `employees.txt` – Sample employee records

## How to Run

```bash
gcc performance.c -o performance
./performance
```

## Concepts Learned
Structures, arrays, functions, pointers, searching, updating and file handling.
